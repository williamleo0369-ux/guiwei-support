# 归位 Guiwei

让每件物品都有归处 · A place for everything

归位帮助你用照片、位置和物品清单记录家中物品，搬家、整理和找东西时随时查找。运营者：William。

Guiwei is a home inventory app for recording photos, storage locations and item lists. Operated by William.

## 当前发布状态

归位正在准备 iPhone 正式发行，尚未上架。计划免费下载，20 件物品免费，超过后一次性解锁新增额度；中国区目标价格为 ¥6，其他地区以 Apple 商店实际显示为准。购买尚在配置与验证，不代表已开放付费。已有物品可继续查看、编辑和导出，备份恢复不收费。

Guiwei is preparing for iPhone release and is not yet on the App Store. The planned free tier includes 20 items, with a one-time purchase to add more. Purchasing is still being configured and tested. Existing records remain accessible, editable and exportable. Backup and restore remain free.
